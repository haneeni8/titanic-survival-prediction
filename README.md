# 🚢 Titanic Survival Prediction Project

# Project Overview & Motivation
This project follows the **CRISP-DM** methodology to analyze the Titanic dataset, clean the data, train a machine learning model, evaluate its performance, and run real-world prediction scenarios. The goal is to understand the socio-economic factors that influenced passenger survival.

## Repository File Structure
- `notebook.ipynb`: Contains the complete data analysis, cleaning, visualization, modeling, and evaluation code.
- `README.md`: Project documentation and summary.

## Libraries Used
- `pandas` & `numpy` (Data manipulation and handling)
- `matplotlib` & `seaborn` (Data visualization and EDA plots)
- `scikit-learn` (Machine learning modeling and evaluation metrics)

## Summary of Results
- Exploratory Data Analysis revealed clear patterns regarding ticket classes and age groups affecting survival rates.
- A **Random Forest Classifier** was successfully trained, achieving solid accuracy and recall scores in predicting passenger outcomes.
